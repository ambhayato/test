# カードキー管理アプリ

会社のカードキー(6枚)の貸出・返却・利用履歴を管理するシンプルなWebアプリです。

## 機能

- カードキー一覧(在庫 / 貸出中をひと目で確認)
- 貸出登録(利用者はマスタから選択、またはフリー入力)
- 返却処理
- カードキーごとの利用履歴一覧(利用者・利用日・返却予定日・返却日)
- 利用者マスタ管理(追加・削除)

左側のナビゲーションから「カードキー一覧」「利用者マスタ管理」「貸出登録」「利用履歴」を切り替えて使います。

## セットアップ(ローカルで試す場合)

```sh
cd card-key-app
npm install
npm start
```

`http://localhost:4000` にアクセスしてください。

データは `data/db.json` に保存されます(初回起動時に自動生成)。このファイルがあるサーバー上で
プロセスを起動し続ける限り、データは保持されます。

## Teamsに追加するまでの手順

このアプリはブラウザで動く小さなWebアプリなので、Teamsの「Webサイト」タブにURLを1つ登録するだけで、
チームのメンバーが同じデータを見られるようになります。ポイントは「アプリ自体をどこかで常時起動しておく」ことです。

### 1. サーバーをどこかで常時起動する

このアプリは1台のサーバー(プロセス)で常に動かし続ける必要があります(ブラウザだけで完結する仕組みではなく、
貸出・返却データをファイルに保存して全員で共有する仕組みのため)。候補は大きく2つです。

| 選択肢 | 概要 | 向いているケース |
| --- | --- | --- |
| 社内の常時電源ONのPC/サーバー | 社内LAN上のIPやホスト名でアクセス(例: `http://192.168.x.x:4000`) | 追加費用なし。社内ネットワーク(VPN含む)内からのみ使う場合 |
| 無料/安価なクラウド(Render, Railway など) | HTTPS付きの公開URLでデプロイ | 自宅や外出先からもアクセスしたい場合 |

どちらにするか決まったら、その環境向けの起動手順(Windowsサービス化、Dockerfile など)は別途用意します。

### 2. 起動したURLをTeamsのチームに追加する

1. アプリを追加したいチーム(またはチャネル)を開く
2. チャネル上部のタブ一覧の「+」をクリック
3. アプリ一覧から「Webサイト」を選択
4. 手順1で用意したURL(例: `http://192.168.x.x:4000` や `https://your-app.onrender.com`)を入力
5. タブの表示名(例: 「カードキー管理」)を入力して保存

これで、チームのメンバーはTeamsのタブを開くだけでアプリにアクセスできます。

### 補足: SharePointのファイルだけで済ませられないか

「Webアプリを公開するほどではない」という場合、SharePoint上のファイルを直接読み書きする方式も検討できますが、
実際には以下の理由でこちらの方が手間が増えます。

- ブラウザからSharePoint/Teamsのファイルを読み書きするには Microsoft Graph API の利用が必要で、
  そのために **Azure ADへのアプリ登録**(社内IT管理者の作業)が必要
- SharePointは通常セキュリティ上の理由でHTML内のスクリプト実行を禁止しているため、
  結局HTMLファイル自体は別の場所でホストする必要がある

そのため、現状の小さなサーバーをどこかで動かし、TeamsにWebサイトタブとして追加する方法が最もシンプルです。
