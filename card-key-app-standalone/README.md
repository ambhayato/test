# カードキー管理アプリ(共有ファイル版・サーバー不要)

`index.html` 1ファイルだけで動く、サーバー不要版のカードキー管理アプリです。
社内の共有ネットワークドライブ上のJSONファイルにデータを保存することで、複数人・複数PCでデータを共有します。

## 必要環境

- **Google Chrome** または **Microsoft Edge**(ブラウザの「File System Access API」という機能を使用しています)
- Safari / Firefox では動作しません

## 使い方

### 1. 初回セットアップ(誰か1人が行う)

1. `index.html` を、全員がアクセスできる共有ネットワークドライブに置く(共有フォルダに置いてもよいですし、各自のPCにコピーして使ってもかまいません。データファイルさえ共有場所にあれば動作します)
2. ブラウザで `index.html` をダブルクリックして開く
3. 「共有データファイルに接続してください」画面で **「新規作成」** を押し、共有ネットワークドライブ内に `card-key-data.json` のようなファイル名で保存する

### 2. 2人目以降のセットアップ

1. 同じ `index.html` を開く(共有ドライブから直接開くか、各自のPCにコピーして開く)
2. 「既存のファイルを開く」を押し、1で作成した共有ドライブ上の `card-key-data.json` を選択する

一度接続すると、次回からは同じブラウザでファイルを開いた際に自動的に再接続を試みます
(ブラウザ側の権限確認画面が出た場合は「再接続する」を押してください)。

### 3. 通常の利用

左側のナビゲーションから「カードキー一覧」「利用者マスタ管理」「貸出登録」「利用履歴」を切り替えて使います。
画面右上の「更新」ボタンや、画面切り替え時に自動的に共有ファイルを再読み込みするので、
他の人が行った貸出・返却も反映されます(それでも最新にしたい場合は「更新」を押してください)。

## 制限事項

- **同時書き込みの競合**: 複数人がほぼ同時に貸出登録・返却操作をすると、後から保存した内容で上書きされる場合があります(排他制御はありません)。頻繁に同時操作が発生する運用には向きません。
- **対応ブラウザ**: Chrome / Edge のみ。Safari / Firefoxでは「このブラウザは非対応です」と表示されます。
- **リアルタイム反映ではない**: 他の人の変更は自動更新(20秒ごと)または画面切り替え時・「更新」ボタンで反映されます。今まさに誰かが操作した直後の状態が即座に見えるわけではありません。
- **接続の切れ直し**: OSやブラウザの再起動後など、ファイルへのアクセス許可が切れることがあります。その場合は「再接続する」ボタンで許可し直してください。

## Teams / SharePointへの公開(GitHub Pages経由)

HTMLファイルをTeams/SharePointにそのままアップロードすると、多くの場合クリックしてもダウンロードされるだけで
アプリとしては開けません(SharePointがHTML内のスクリプト実行を防ぐための仕様のため)。
そこで、このフォルダを **GitHub Pages** で公開し、そのURLをTeamsの「Webサイト」タブに登録する方法を用意しています
(`.github/workflows/deploy-pages.yml` で自動デプロイされます)。

### 1. GitHub Pagesを有効化する(リポジトリの管理者が1回だけ行う)

1. GitHubのリポジトリ画面で **Settings → Pages** を開く
2. 「Build and deployment」の **Source** を **GitHub Actions** に設定する

これで、`card-key-app-standalone/` 配下に変更をpushするたびに自動でPagesへデプロイされます
(`.github/workflows/deploy-pages.yml` が実行されます)。手動で今すぐデプロイしたい場合は、
GitHubの **Actions** タブから `Deploy card-key-app-standalone to GitHub Pages` を選び、
「Run workflow」で手動実行することもできます。

### 2. 公開されたURLを確認する

デプロイが完了すると、GitHubの **Settings → Pages** 画面、または該当ワークフローの実行結果に
公開URL(例: `https://<組織名またはユーザー名>.github.io/<リポジトリ名>/`)が表示されます。

### 3. TeamsのWebサイトタブに追加する

1. 追加したいチーム(チャネル)を開く
2. タブ一覧の「+」→「Webサイト」を選択
3. 2で確認したURLを入力し、タブ名(例:「カードキー管理」)を付けて保存

これで、チームのメンバーはTeamsのタブを開くだけでこのアプリにアクセスできます。
データの共有・接続方法は上記の「使い方」の手順と同じです(各自のブラウザで共有ドライブ上のデータファイルに接続します)。

## Node.js版(card-key-app)との違い

このリポジトリには、常時起動するサーバーを使う `card-key-app`(Node.js版)もあります。
どちらを使うべきかの比較:

| | サーバー版 (card-key-app) | 共有ファイル版 (このフォルダ) |
| --- | --- | --- |
| 事前準備 | サーバーをどこかで常時起動しておく必要あり | 不要(共有ドライブにファイルを置くだけ) |
| Teams連携 | 「Webサイト」タブでURLを登録できる | Teamsのタブには組み込めない(各自ブラウザでindex.htmlを開く運用) |
| 対応ブラウザ | 制限なし | Chrome / Edgeのみ |
| 同時書き込み | サーバーが調停(競合しにくい) | 競合の可能性あり |
