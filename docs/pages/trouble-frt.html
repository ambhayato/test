失敗したリクエストのトレース（FRT）

失敗したリクエストのトレース（Failed Request Tracing）は、 エラーの詳細な原因調査に役立つ IIS の機能です。

有効化の手順

  1. IIS マネージャーでサイトを選択
  2. [失敗したリクエストのトレース] をダブルクリック
  3. [有効] にチェックを入れてパスを指定
  4. トレースするルールを追加（例: ステータスコード 500）

web.config での設定

<system.webServer>
  <tracing>
    <traceFailedRequests>
      <add path="*">
        <traceAreas>
          <add provider="ASP" verbosity="Verbose" />
          <add provider="ASPNET"
               areas="Infrastructure,Module,Page,AppServices"
               verbosity="Verbose" />
          <add provider="WWW Server"
               areas="Authentication,Security,Filter,StaticFile,Cache,RequestNotifications"
               verbosity="Verbose" />
        </traceAreas>
        <failureDefinitions statusCodes="400-599" />
      </add>
    </traceFailedRequests>
  </tracing>
</system.webServer>

Note: トレースログはサイズが大きくなるため、問題解決後は無効化することを推奨します。
