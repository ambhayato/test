Azure App Service

Azure App Service は、IIS をマネージドサービスとして利用できる PaaS です。 インフラ管理不要で Web アプリケーションをデプロイできます。

App Service の作成（Azure CLI）

# リソースグループの作成
az group create --name myResourceGroup --location japaneast

# App Service プランの作成（Windows）
az appservice plan create \
  --name myAppServicePlan \
  --resource-group myResourceGroup \
  --sku B1 \
  --is-windows

# Web アプリの作成
az webapp create \
  --name myWebApp \
  --resource-group myResourceGroup \
  --plan myAppServicePlan \
  --runtime "DOTNET|6.0"

デプロイ方法

  • ZIP デプロイ - シンプルなファイルのアップロード
  • GitHub Actions - CI/CD パイプライン
  • Azure DevOps - エンタープライズ CI/CD
  • FTP/FTPS - レガシー互換
  • Visual Studio 発行 - 開発環境からの直接デプロイ

ZIP デプロイの例

az webapp deployment source config-zip \
  --resource-group myResourceGroup \
  --name myWebApp \
  --src myapp.zip
