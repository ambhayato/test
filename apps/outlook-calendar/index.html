Azure AD アプリ設定

初回のみ、Azure AD に登録したアプリの情報を入力してください。
入力値はこのブラウザにのみ保存されます。

📖 Azure AD アプリの登録手順
  1. Azure Portal を開き「アプリの登録」へ
  2. 「新規登録」→ 任意の名前を入力
  3. リダイレクト URI に を設定（シングルページアプリ）
  4. 「APIのアクセス許可」から以下を追加（委任）:
    User.ReadBasic.All、Calendars.Read
  5. 必要に応じて管理者の同意を付与
  6. 「概要」からアプリケーション (クライアント) ID とディレクトリ (テナント) ID をコピー
